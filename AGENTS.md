# Instrucciones para agentes

Este repositorio es el portafolio personal de Samuel Santiesteban. Consulta `docs/PLAN-PORTAFOLIO.md` y respeta el alcance solicitado. Comunica experiencia real sin inventar cargos, métricas, proyectos ni resultados.

## CodeGraph

Si existe `.codegraph/` en la raíz, usa `codegraph_explore` antes de buscar texto o leer archivos para localizar o entender código; alternativamente usa `codegraph explore "<símbolos o pregunta>"`. Si no existe, no crees el índice por defecto.

## Contenido y privacidad

- Confirma información profesional antes de publicarla. No publiques código, marcas, capturas o datos internos de clientes sin autorización; también revisa los ejemplos anónimos.
- No leas ni expongas secretos o archivos de entorno salvo necesidad estricta. No los incluyas en documentación o respuestas.
- El plan no autoriza por sí mismo crear repositorios, desplegar, enviar mensajes o contratar servicios.

## Trabajo y validación

- Explora el estado y los cambios existentes, respeta el trabajo ajeno e implementa en unidades proporcionadas. Documenta decisiones y evidencia para cambios sustanciales.
- El plan se inspira en ODD, pero no implica que Gentle AI o una skill estén instalados. No instales herramientas ni crees un sistema multiagente sin necesidad concreta.
- Distingue propuestas, simulaciones y resultados reales. No inventes verificaciones ni muestres ejecuciones ficticias como reales.
- En cambios visuales considera móvil y escritorio, teclado, nombres accesibles, contraste y movimiento reducido. La información esencial no debe depender de animaciones ni de un asistente.
- Para IA, explica datos, permisos, transferencias externas, costos y límites; prueba respuestas sin evidencia y fallos. El asistente público no debe tener acceso administrativo a GitHub ni a código privado.
- Elige comprobaciones proporcionales con los scripts de `package.json` y pruebas de navegador para interacciones cuando sea posible. Informa resultados y límites. No cambies dependencias o despliegue sin relación con la tarea.
